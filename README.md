# codomax-blogspace
A responsive blog application built with HTML, CSS, and JavaScript, featuring user authentication, blog creation, publishing, editing, and management.
BlogSpace is a responsive frontend blog application built with HTML, CSS, and JavaScript. It allows users to register, log in, create and publish blog posts, save drafts, edit and delete articles, and explore published content. The application features a clean, user-friendly interface and uses browser local storage to manage user accounts and blog data.
